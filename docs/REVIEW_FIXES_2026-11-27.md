## Безопасность (невидимо для игрока)

- **CSP webview.** Из `connect-src` убраны dev-адрес `http://127.0.0.1:3000` и
  все внешние хосты. Интерфейс сам в сеть не ходит, вся сеть идёт через Rust.
  Даже при XSS из окна теперь нельзя отправить данные на сторонний сервер через
  `fetch`.
- **Защита от распаковочной бомбы.** Распаковка нативных библиотек больше не
  пишет больше заявленного размера записи в архиве.
- **Ключ апдейтера.** Тест сверяет ключ апдейтера, вшитый в приложение, с
  ключом в `tauri.conf.json`, по которому подписи проверяет CI.

## Сознательно не исправлено (и почему)

| Пункт ревью | Причина |
|---|---|
| Хеш установщика и срок действия в подписанном control-манифесте (откат версии) | `ControlManifest` парсится с `deny_unknown_fields`: новое поле сломает обновление у всех уже установленных 1.10.0. Нужен отдельный план: новый URL манифеста или двухфазный выпуск |
| 2FA без повторного ввода пароля | Исправляется на сервере (`website/`), не в лаунчере |
| `settings_set` и `settings_reset` в UI-потоке | Создают и удаляют иконку в трее; на macOS это нужно делать в главном потоке. Пишут маленький файл, на практике незаметно |
| Переиспользование HTTP-клиента в metadata/Java | 3–5 запросов за запуск, выигрыш — десятки мс. Статический `reqwest::Client` ломается между tokio-рантаймами в тестах |
| `String`-ошибки → типизированные | Рефакторинг ~226 сигнатур; без компилятора делать вслепую нельзя |
| Удаление Electron-стека | Это продуктовое решение: он нужен как мост обновления для клиентов 1.9.x |
| Workspace, вынос `website/`, кэш Cargo, cargo-deny, Dependabot | Касаются только разработки и CI, игрок их не заметит. Кэш в подписанном релизном пайплайне требует отдельного решения |
| `os.version` в правилах Mojang, Job Object до старта процесса, allowlist JVM-флагов, цепочки симлинков в TAR | Low-риск или нужен локальный доступ к файлам. Выигрыш для игрока минимален, а риск регрессии на запуске заметный |
