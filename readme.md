# NATUX WORLD — Minecraft Server Site

Сайт для Minecraft-сервера NATUX WORLD с донат-магазином, оплатой и автоматической выдачей привилегий.

Основные данные проекта:

- сайт: `natuxworld.ru`;
- Minecraft IP: `mc.natuxworld.ru`;
- VK: `https://vk.com/natuxworld`;
- логотип: `public/logo.svg`.

Проект задуман в тёмной красно-чёрной стилистике, похожей на игровые PvP/Anarchy магазины: выбор ранга, выбор срока, ввод ника, оплата и выдача доната на сервер.

## Основной сценарий покупки

1. Игрок открывает магазин.
2. Выбирает ранг.
3. Выбирает срок действия.
4. Вводит Minecraft-ник.
5. Нажимает кнопку покупки.
6. Сайт создаёт заказ.
7. Игрок переходит на оплату.
8. Платежная система отправляет webhook на backend.
9. Backend подтверждает оплату.
10. Backend выдаёт донат через RCON.
11. Игрок видит успешный статус заказа.

## Оплата

Платежная система выбирается отдельно.

Подходящие варианты:

- YooKassa;
- Robokassa;
- FreeKassa;
- CloudPayments;
- Lava;
- Enot;
- UnitPay.

Важно: донат выдаётся только после подтверждения оплаты через webhook, а не после обычного возвращения пользователя на сайт.

---

## Выдача доната

Первый релиз предполагает выдачу через RCON.

Пример логики:

- временный ранг выдаётся через LuckPerms `addtemp`;
- вечный ранг выдаётся через LuckPerms `add`;
- каждая выдача логируется;
- повторный webhook не должен повторно выдавать донат;
- при ошибке RCON создаётся задача на повторную выдачу.

## Безопасность

Обязательные правила:

- не хранить пароли в открытом виде;
- не хранить RCON password в коде;
- использовать `.env`;
- проверять подпись платежных webhook;
- не доверять цене с frontend;
- валидировать Minecraft-ник;
- защищать админку авторизацией;
- использовать HTTPS;
- ограничить доступ к RCON по IP;
- логировать важные действия.

## Как запустить локально

1. Установить зависимости:

`npm install`

2. Запустить dev-сервер:

`npm run dev`

3. Открыть сайт:

`http://localhost:3000`

4. Проверить сборку:

`npm run build`

5. Проверить TypeScript:

`npm run typecheck`

## Как проверить покупку в mock-режиме

1. Открыть `/shop`.
2. Выбрать ранг.
3. Выбрать срок.
4. Ввести ник, например `Notch`.
5. Нажать `Purchase`.
6. Откроется страница заказа `/order/...`.
7. Нажать `Mock оплатить и выдать`.
8. Заказ станет `paid/delivered`.
9. На странице появятся mock RCON-команды выдачи.
10. В `/admin` заказ появится в таблице.
